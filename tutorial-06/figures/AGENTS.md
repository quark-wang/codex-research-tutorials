# Figure-specific guidance

- [FIG-DATA-01] Plot committed tables under `results/`; never recompute chains in figure code.
- [FIG-STYLE-02] Export a readable 300 dpi PNG and matching vector PDF with a colorblind-safe palette.
- [FIG-ERROR-03] Label error bars as SEM across independent chains, not autocorrelation-corrected uncertainty.
- [FIG-REFERENCE-04] Draw exact Tc as a labeled reference line, never as simulated data.
- [FIG-VERIFY-05] Verify every release figure exists in both formats and has nonzero dimensions.
