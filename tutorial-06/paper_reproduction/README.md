# Independent reproduction of Saratz et al. Figure 9(a-b)

This subtree independently reproduces the scientific relationships in panels 9(a-b) of:

> N. Saratz et al., “Critical exponents and scaling invariance in the absence of a critical point,” *Nature Communications* **7**, 13611 (2016), DOI: [10.1038/ncomms13611](https://doi.org/10.1038/ncomms13611).

It does **not** contain the authors' bitmap or numerical data. All points are newly generated by this project.

## What is matched to the paper

- unfrustrated square-lattice 2D Ising model;
- zero external field;
- reduced units `J = k_B = 1`;
- lattice sizes `L = 10, 20, 40`;
- temperature range `T/J = 1.5...3.0`;
- panel (a): finite-size magnetization plus the exact Onsager `m_infinity(T)` curve;
- panel (b): `m_L/m_infinity` versus `L |tau|^nu`, with `tau=(T-Tc)/Tc` and the 2D-Ising value `nu=1`.

## What is selected for this tutorial

The cited Figure 9 caption and associated methods text do not provide its random seeds or a complete per-temperature sampling schedule. This project therefore declares its own reproducible budget:

- 4 independent chains per `(L,T)`;
- 3,000 equilibration sweeps per chain;
- 9,000 measurement sweeps per chain;
- one stored magnetization every 9 measurement sweeps (1,000 samples per chain);
- master seed `20261121`;
- periodic boundaries and the operational estimator `m_L = <|M|>/N`;
- ordered initial state and an even-lattice red-black Metropolis sweep.

These choices make this an **independent method reproduction**, not a point-for-point duplication or a publication-precision convergence study. The SEM is computed across independent chains and is not corrected using an integrated autocorrelation time.

## Run

From the repository root:

```powershell
python paper_reproduction/run_figure9_reproduction.py
```

For a fast plumbing check that writes to a separate directory:

```powershell
python paper_reproduction/run_figure9_reproduction.py --quick
```

The full run writes:

- `results/reproduction/figure9_chain_summary.csv` — one row per independent chain;
- `results/reproduction/figure9_summary.csv` — chain means and SEM;
- `results/reproduction/figure9_metadata.json` — provenance, hashes, runtime, and quantitative checks;
- `results/figures/fig08_saratz_figure9ab_reproduction.png`;
- `results/figures/fig08_saratz_figure9ab_reproduction.pdf`.

`numba` is used when installed. The source has a pure-Python fallback for tiny checks, but the declared full run is intended to use Numba acceleration.
